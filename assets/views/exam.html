Question Palette

  • Not Visited means you have not opened the question yet.
  • Not Answered means you have viewed the question but not saved an answer.
  • Answered means your selected option has been saved.
  • Marked for Review means you want to revisit the question.
  • Answered and Marked for Review will be considered for evaluation.

Answering Questions

  • Select an option by clicking on it.
  • Use Clear Response to remove the selected option.
  • Use Save & Next to save your answer and move ahead.
  • Use Mark for Review & Next to mark the current question for review.
  • You may return to any question from the palette during the test.

Navigation

  • The timer at the top right shows the remaining test time.
  • The question palette can be collapsed to increase question viewing space.
  • Clicking a question number opens that question directly.
  • When the timer reaches zero, the test is submitted automatically.

Marking Scheme

  • Correct answer: +5 marks.
  • Wrong answer: -1 mark.
  • Unanswered or skipped question: 0 marks.
  • Only saved answers are counted in the final result.
